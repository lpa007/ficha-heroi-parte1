# 🛡️ Ficha de Personagem - Nymeria | Herdeira do Eclipse

Esta aplicação web é uma ficha de personagem interativa desenvolvida para **Nymeria**, uma Paladina de nível 20, Princesa de Aurelia e Descendente do Deus Elyndor. O projeto combina um visual focado na temática fantástica/cósmica com uma interface responsiva construída em HTML5 e CSS3.

---

## 📌 Sobre o Projeto

O objetivo deste projeto é apresentar as informações detalhadas da personagem em formato de *dashboard* interativo para RPG/Guilda.

A estrutura é dividida em quatro partes principais:
- **Perfil & Biografia:** Apresentação da personagem, classe, nível, origem e lore.
- **Atributos & Habilidades:** Exibição das estatísticas com barras visuais e habilidades especiais.
- **Inventário & Conquistas:** Grade de itens, relíquias com selos de raridade e marcos históricos.
- **Contato com a Guilda:** Formulário interativo para envio de missões e convocação.

--- 

## 🔍 Processo de Pesquisa e Desenvolvimento

A criação da página e da ficha da personagem **Nymeria, a Herdeira do Eclipse** envolveu um processo estruturado em quatro etapas principais de pesquisa, planejamento e execução técnica:

### 1. Pesquisa Temática & Construção de *Worldbuilding*
- **Pesquisa de Referências Visuais & *Lore*:** Investigação de universos de RPG de fantasia medieval  para definir uma narrativa coesa. A escolha da paleta mística reflete a dualidade da personagem (Luz e Trevas / Deus Elyndor).
- **Estruturação de Dados de RPG:** Estudo sobre como organizar atributos (*Força, Inteligência, Sabedoria...*), níveis, inventário e itens lendários de forma intuitiva para o leitor.

### 2. Pesquisa de UI/UX e Design System
- **Tipografia Temática:** Testes de fontes no *Google Fonts* para encontrar uma combinação elegante entre uma fonte serifada imponente para títulos (*Cinzel*) e uma fonte sem serifa legível para textos longos (*Inter*).
- **Paleta de Cores e Variáveis CSS:** Levantamento e teste de contraste utilizando variáveis CSS (`:root`), garantindo acessibilidade e harmonia visual
- **Hierarquia Visual:** Definição da disposição dos componentes (cartões de inventário, barras de progresso de atributos e seção de contato da guilda) para garantir uma navegação fluida.

### 3. Pesquisa Técnica e Arquitetura CSS
- **Layouts Flexíveis (*Flexbox & CSS Grid*):** Aplicação de *Flexbox* para o alinhamento da barra de navegação, cabeçalho e rodapé, e *CSS Grid* para a distribuição automática dos cartões do inventário.
- **Técnicas de Responsividade:** Estudo e implementação de *Media Queries* e unidades relativas  para garantir que o layout se adapte sem erros a telas de computadores, *tablets* e dispositivos mobile.

### 4. Boas Práticas e Documentação
- **Acessibilidade e Semântica:** Uso de marcas semânticas do HTML5 (`<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`) e atributos de acessibilidade (`alt`, `aria-label`).
- **Documentação Técnica:** Pesquisa de estruturas de *README.md* no GitHub para apresentar o projeto de forma profissional, incluindo capturas de tela, links de demonstração, fichas técnicas e organização dos arquivos.
